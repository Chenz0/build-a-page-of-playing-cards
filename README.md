# Proyecto de Cartas de Juego (Playing Cards)

Un diseño sencillo y elegante de cartas de póker utilizando **HTML5** y **CSS3 (Flexbox)**. Este proyecto demuestra el uso de alineaciones flexibles y transformaciones para crear componentes visuales reutilizables.

## 🚀 Vista Previa
Este proyecto muestra tres cartas icónicas:
- **As de Picas (♠)**
- **10 de Corazones (♥)**
- **Rey de Diamantes (♦)**

Las cartas incluyen un efecto de rotación de 180 grados en la esquina inferior derecha para imitar el diseño de una baraja real.

## 🛠️ Tecnologías utilizadas
* **HTML5**: Estructura semántica.
* **CSS3**: 
    * **Flexbox**: Para la distribución interna de los elementos de la carta.
    * **Transforms**: Para invertir los símbolos inferiores.
    * **Responsive Design**: Las cartas se ajustan según el ancho de la pantalla.

## 📂 Estructura de archivos
El proyecto está dividido para mantener un código limpio:
* `index.html`: Contiene el marcado de las cartas.
* `styles.css`: Contiene toda la lógica visual y el diseño.

## 🔧 Instalación y Uso
1. Clona este repositorio o descarga los archivos.
2. Asegúrate de que `index.html` y `styles.css` estén en la misma carpeta.
3. Abre el archivo `index.html` en cualquier navegador moderno.

Puedes ver este proyecto en vivo a través de **GitHub Pages**. (Una vez configurado en Settings > Pages).
